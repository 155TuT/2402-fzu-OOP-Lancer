# 快速批阅指南
**项目简介：** 这是一个简易的c++深度学习框架，名字叫tenet，可以读作ten-net，意思是~~它可以让我的平时分加10分~~
## 文件介绍/浏览步骤
项目中有以下文件，我分别介绍它们的功能

1. 在include文件夹下是汇报作业的本体，所有代码都在这里
2. example1.cpp是使用这个框架完成简单的线性回归的例子，5个输入，一个输出，c++11标准下可以直接运行，可以先运行这个程序证明这是真的能跑的框架（其中func函数就是他要拟合的函数，如果愿意也可以改成你想要的）

## 项目运用到的面向对象知识
可以说这个项目基本上和oop关联非常大，基本每一部分都大面积运用了oop中的知识点
### 实现张量类
这是一个二维矩阵，通过类封装，支持了矩阵乘法等操作
共计350行代码
#### 1. 重载运算符
- 支持矩阵乘法/浮点数和矩阵的加法乘法，并支持广播机制

实现+= * +等各种课程中常见的重载
利用友元重载运算符可以重载一些如 浮点数+矩阵 的操作
#### 2. 函数（方法）
写了一些按维度求和/访问矩阵中的元素的函数
apply函数可以传入函数，并将函数作用于整个矩阵，在实现激活函数和损失函数可被大量运用，也可以进行矩阵的初始化之类的操作
### 实现整个框架
我将每一层（如激活函数层，全连接层）都定义成一个类，其中他们有一个共同的父类Layer，其中主要有参数和梯度两个对象
*（但其实我最后发现这个实现并不是特别好，把梯度变为之前的张量类的一个对象好像更符合实际）*
- 这个父类是一个虚函数，需要重写forward和backward函数

不同层forward函数和backward函数的实现是这个项目的核心，数学推导的过程也花了占比非常大的时间，但和面向对象关系较小，且很难说清，故这里暂略
#### 继承的妙用
在这里必须要使用继承而不能单独定义每个层
因为在forward需要获取上一层传过来的层的地址，这样才能构建计算图，backward时候才知道把梯度 $\frac{\partial L}{\partial Z_1}$ 传给谁
而整体的forward方法是用户定义，你无法知道传过来的是全连接层还是哪种激活函数层，故传参是可以统一使用父类
- 这里使用了以下特性：可以将将派生类指针或引用转换为基类指针或引用
### 实现训练
这里通过让用户同过继承Module类的方法构建模型，并记录所有参数的地址，让优化器将参数和梯度做点乘即可
